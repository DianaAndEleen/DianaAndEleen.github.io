# 《清晨的色彩》视觉小说化：分镜与配乐

这份文档是给「沉浸剧场」用的施工图：把 4 节正文切成 **30 个场景**，
每个场景一张定制插画（AI 生成、逐场景连续），并给出这个场景**想要什么风格的配乐**。

- 分镜图片：`assets/images/scenes/morning-colors/ch<节>-<场>.jpg`（1600×900）
- 生图任务表：`sider-batch/tasks/清晨的色彩-场景图-<节>.jsonl`（本地出图工具目录，不入库）
- 场景配置：`data/scenes.json` → `books["morning-colors"].chapters`
- 配乐：本文档第 4 节是「选曲清单」，你先看风格，挑到合适的曲子后丢进
  `assets/audio/` 即可（改法见第 5 节）。在真曲到位之前，每个场景先由
  `assets/js/music.js` 实时合成一段同风格的 demo，**开箱即用、无版权问题**。
  （其中「第二节 · 中午换一家吃吧」已经挂了一首真实曲目
  `assets/audio/carefree.mp3` 作为示范，用来验证「真曲优先、换场交叉淡入」这条路径。）

## 1. 连续性是这么做出来的

一次生成 30 张图，最容易崩的是「人物每次长得不一样」和「看着不像一部片子」。
这里的做法是三层锚点：

1. **画风/造型锚点图**（`sider-batch/refs/mc-anchor.png`）：先用
   `refs/嘉然.png` + `refs/乃琳.png` 两张角色设定图，生成一张「两人在枝江大楼前」的
   定稿镜头，把画风、上色、光照基调和两位角色在这部作品里的服装一次性定死。
   - 乃琳：银白长发、蓝紫眼睛、**白衬衫 + 深色高腰西装裙 + 黑色高跟鞋**（律师人设，
     与设定图里的黑色礼裙不同，所以在锚点图里就换成职场装并固定下来）
   - 嘉然：棕色微卷长发、头顶呆毛、脑后大红色蝴蝶结、蓝色大眼睛、粉色蓬松连衣裙、
     小皮鞋 + 草莓图案粉色短袜
2. **每个场景都把锚点图当「图 1」**：提示词里写明「严格延续图 1 的画风与人物造型，
   但构图按本场景重排」，这样既锁住一致性，又不会让 30 张图都长成同一张。
3. **同场景接续用上一镜做参考**：同一个连续地点（比如电梯里的两镜、火锅店里的两镜、
   深夜卧室的几镜、黄昏街道的两镜）会把上一张成品图一起作为参考图，环境、光线、
   衣着自然接得上。

另外两处细节：

- 第 3 节夜晚的卧室（场景 19–24、26–27）里乃琳穿的是**宽松米白睡衣、头发散乱**，
  这是剧本里写明的居家状态，所以这几个镜头自成一组、彼此参考，不会和白天串味。
- 所有提示词都要求「画面中不要出现任何文字」，避免出现糊掉的字幕/招牌。

## 3. 场景与「幕」的对应关系

剧场模式里，**同一个场景配置覆盖的连续段落会被合并成一幕**：背景不重复淡入淡出，
场景标题只在进入时出现一次，配乐也只换一次。所以第 3 节里 68 段文字只会有 12 次
换场、12 次换曲，而不是 68 次。

## 4. 换成你自己选的真曲

配乐分三级，优先级从低到高：

1. `books["morning-colors"].mood`：整本书的兜底氛围（现在是 `morning`）；
2. 每个场景的 `mood`：上表最后一列的 demo，实时合成、零版权；
3. 每个场景的 `bgm`：真实音频文件路径——**你挑到曲子之后填的就是它**。

只要某一场景写了 `bgm`，这一场就改用真实音频；左右两场会各自按自己的
`mood` 走合成音。左上角的曲名标签也会跟着变：合成氛围显示它的名字
（如「♪ 心动」），真实音频显示「♪ 自选曲目」，鼠标悬停在上面可以看到
这一场 `musicStyle` 里写的选曲需求。

举例，如果第 24 场（我想象中的告白）你选了一首小提琴与竖琴的曲子：

```powershell
# 1. 把文件放进 assets/audio/morning-colors/（目录不存在就新建）
# 2. 打开 data/scenes.json，找到这一场，加上 bgm 字段：
```

```json
{ "id": "ch3-09", "img": "morning-colors/ch3-09", "from": 36, "to": 45,
  "name": "我想象中的告白", "mood": "dream",
  "musicStyle": "华尔兹感的梦境弦乐，加一点盒式琴，朦胧、飘、柔焦",
  "bgm": "assets/audio/morning-colors/ch3-09-waltz.mp3" }
```

配乐会在进入这一幕时**交叉淡入切换**（旧的一路淡出、新的一路淡进），
在 `data/scenes.json` 里保留 `mood` 可以确保音频加载失败时仍有兜底。
选曲时建议统一两点：**整本书尽量同一套配器**（钢琴/弦乐），
以及**相邻场景的音量响度接近**，不然换场会显得跳。

请只使用你有权使用的音频，并把来源补进 `CREDITS.md`。

## 5. 重新生成或替换某一幕

生图任务表在 `sider-batch/tasks/`，一行一个场景，字段说明见
`sider-batch/教程.md`。想重画某一幕，把那一行单独存成一个小文件再跑即可：

```powershell
cd D:\Code\DianaAndEleen\sider-batch
node sider.mjs batch "tasks/清晨的色彩-场景图-3.jsonl" --concurrency 1 --out "out-场景图"
```

出图后需要压成网页用的 1600×900 JPEG，这一步由
`tools/build-scene-images.py` 完成（它会按场景号裁切、压缩并写到
`assets/images/scenes/morning-colors/`）：

```powershell
python tools/build-scene-images.py
```

改完配置想确认演出效果，可以跑一次剧场冒烟测试（会依次走完四节、打印每一场的
标题 / 背景图 / 配乐，并把截图写到 `.qa/`）：

```powershell
node tools/qa-theater.mjs http://127.0.0.1:8099
```
