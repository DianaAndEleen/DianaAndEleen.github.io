# Sider 批量生图 · 教程

一句话说明：**你在 CSV 表格里一行写一条提示词，双击一个 bat，就批量出图。**

这个文件夹是自包含的，整个复制到别的电脑也能直接跑（前提是那台电脑能上 sider.ai）。

---

## 0. 文件夹里有什么

| 文件 / 目录 | 作用 |
| --- | --- |
| `1-检查账号.bat` | **先双击这个**，确认账号、token、代理都正常 |
| `2-批量生成.bat` | 批量出图，默认跑 `tasks\图生图示例.csv` |
| `3-单张生成.bat` | 输入一句提示词生成一张，用来试词 |
| `sider.mjs` | 主程序（上传 / 生成 / 下载 / 批量调度） |
| `transport.mjs` | 网络层（代理自动探测、SSE 解析、图片下载） |
| `.credentials.json` | 你的登录 token，**不要外发** |
| `tasks\` | 放任务表的地方 |
| `refs\` | 放参考图的地方 |
| `out\` | 出图目录（运行后自动生成） |

---

## 1. 开跑前的三件事

1. **Node.js 要装好。** 命令行输入 `node -v` 能打印版本号就行（本机是 v24.16.0）。
2. **VPN / 代理必须开着。** 直连 sider.ai 是不通的。脚本会自动读 Windows 系统代理，
   **不需要你配任何环境变量**（`node sider.mjs` 不带参数时会打印探测到的代理地址）。
   读不到系统代理时会自动扫一遍本机常见代理端口（7890 / 7891 / 7897 / 7898 / 7899 /
   10808 / 10809 …），用真实请求挑出能到 sider.ai 的那个；端口很特殊的话，把地址写进
   `sider-batch/.proxy`（一行，例如 `http://127.0.0.1:7899`）就会优先用它，
   管理台的「出图返修 → 网络诊断」也能直接填。
3. **token 有效期到 2027-05-03。** 已写在 `.credentials.json` 里，过期了看第 9 节。

## 3. 第二步：写任务表

任务表就是一个 CSV（用 Excel 或记事本编辑都行）。**一行 = 一次生成 = 至少一张图。**

打开 `tasks\图生图示例.csv` 看看：

```csv
id,prompt,refs,model,quality,resolution,aspectRatio
diana-style,"图1是画风参考，图2是角色参考。用图1的画风重绘图2的角色……",refs/Diana.jpg|refs/常服.png,gemini-2.5-flash-image,,,3:4
```

第一行是**表头，必须原样保留**。从第二行开始每行一个任务。

### 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 建议填 | 任务名，决定输出位置 `out\<id>\<id>.png`。不填自动叫 `task-001` |
| `prompt` | **必填** | 提示词，中文英文都行 |
| `refs` | 不用图就不填 | 参考图路径，**多个用 `\|` 分隔**，顺序就是提示词里的「图1、图2」 |
| `model` | 不填默认 `gpt-image-2` | 模型 id，见第 7 节 |
| `quality` | 不填默认 `low` | `low` / `medium` / `high`，越高质量越贵 |
| `resolution` | 不填默认 `1K` | `1K` / `2K` / `4K` |
| `aspectRatio` | 不填默认 `1:1` | `1:1` `3:4` `4:3` `16:9` `9:16`，或 `Auto` |

### 两个容易踩的坑

**① 提示词里带逗号，必须用英文双引号包起来。** 比如上面那行 `prompt` 里有很多逗号，
所以整段被 `"` 包住。不带逗号的提示词可以直接写。

**② 用 Excel 另存 CSV 时，编码要选「CSV UTF-8（逗号分隔）」。**
如果只选普通的「CSV（逗号分隔）」，中文会存成 GBK——脚本虽然会自动识别 GBK 兜底，
但建议还是存 UTF-8，最省事。

> 不想折腾 Excel 的话，也可以用 JSONL 格式（一行一个 JSON），路径和字段一一对应，
> 示例见 `sider\tasks.example.jsonl`，命令完全一样。

## 4. 第三步：放参考图

把图丢进 `refs\` 目录，然后在 CSV 里写**相对这个文件夹的路径**：

```csv
refs/Diana.jpg|refs/常服.png      ← 用两张参考图
refs/我的照片.jpg                  ← 用一张
（留空）                            ← 纯文字生成，不用参考图
```

路径带空格或中文都没问题。参考图的顺序有意义——第一张就是提示词里说的「图1」。

---

## 5. 第四步：批量跑

双击 **`2-批量生成.bat`**。它会跑默认的示例任务表。

想跑自己的表，两种方式：

* **拖拽**：把你的 csv 直接拖到 `2-批量生成.bat` 图标上松手；
* **改 bat**：用记事本打开 `2-批量生成.bat`，把 `TASKS` 那行改成你的文件名。

命令行写法（推荐熟悉之后用，可以调并发）：

```powershell
cd D:\Code\DianaAndEleen\sider-batch

# 跑一个任务表，并发 2
node sider.mjs batch tasks\我的任务.csv --concurrency 2 --out out

# 在命令行统一指定默认模型，任务表里没写的字段就用这个
node sider.mjs batch tasks\我的任务.csv --model gpt-image-2 --quality low --resolution 1K --ratio 1:1
```

跑起来长这样：

```
batch: 3 task(s), model=gpt-image-2, out=out
  ok   cat-window -> out\cat-window\cat-window.png (24.3s)
  ok   lighthouse -> out\lighthouse\lighthouse.png (31.8s)
  FAIL logo-mark: generation failed: ...
done: 2/3 ok
```

**失败的任务不会影响其他任务**，会继续往下跑，失败原因记在结果文件里。

## 7. 模型和点数速查

点数是**每次生成扣一次**，`gpt-image-2` 按质量分档：

| model | 名称 | 点数 |
| --- | --- | --- |
| `gpt-image-2` | GPT Image 2 | low **2** / medium **5** / high **20** |
| `gpt-image-2.5-sunburst` / `-flare` | GPT Image 2.5 | 看账号配额 |
| `gemini-2.5-flash-image` | Nano Banana | 5 |
| `gemini-3.1-flash-lite-image` | Nano Banana 2 Lite | 4 |
| `gemini-3.1-flash-image-preview` | Nano Banana 2 | 8 |
| `gemini-3-pro-image-preview` | Nano Banana Pro | 15 |
| `doubao-seedream-4-0-250828` | Seedream 4.0 | 2 |
| `doubao-seedream-4-5-251128` | Seedream 4.5 | 3 |
| `doubao-seedream-5-0-260128` | Seedream 5.0 lite | 2 |
| `doubao-seedream-5-0-pro-260628` | Seedream 5.0 pro | 4 |

**省钱建议：先用 `--quality low` 试提示词，定稿了再换 `medium` 重跑一遍。**

引擎的差异（实测）：要做**粗描边软萌 Q 版**用 `gemini-2.5-flash-image`，
要**忠实还原角色设定**用 `gpt-image-2`。

## 8. 常用命令速查

```powershell
cd D:\Code\DianaAndEleen\sider-batch

node sider.mjs models                      # 看可用模型和点数
node sider.mjs upload refs\Diana.jpg       # 只是上传，打印 fileId
node sider.mjs gen "一只猫" --out out       # 单张，文字生成
node sider.mjs gen "改成水彩" --ref refs\Diana.jpg,refs\常服.png --ratio Auto
node sider.mjs batch tasks\文生图示例.csv --concurrency 2
node sider.mjs                             # 不带参数 = 打印帮助
```

全局可加的参数：`--model` `--quality` `--resolution` `--ratio` `--out` `--concurrency`。
这些在命令行上给的值是**默认值**，任务表里写了同名字段就以任务表为准。

**并发怎么选**：默认 2 已经够快。`--concurrency 4` 更快，但并发太高有可能触发风控，
建议不要超过 4。

## 9. 出问题怎么办

| 现象 | 原因 / 处理 |
| --- | --- |
| 报 `token 无效或已过期` | token 到期。见下面「怎么换 token」 |
| 报 `403` 且返回一堆 HTML、里面有 `Just a moment` | 触发了 Cloudflare。检查是不是自己手动改了 `sider.mjs` 里的请求头（**千万不要加 `accept` 头，也不要带 cookie**，这是实测踩出来的坑） |
| 所有请求都超时 / 连不上 | VPN 没开，或代理端口变了。先开 VPN，再跑 `node sider.mjs` 看它探测到的代理地址。报错里写 `Failed to connect to sider.ai` 说明这次根本没走代理；写代理地址才是代理转发失败。系统代理读不到时脚本会自动扫常见端口，也可以把地址写进 `sider-batch/.proxy` |
| 中文提示词变乱码 | CSV 存成非 UTF-8 了。用 Excel 的「CSV UTF-8」另存，或改用 JSONL |
| 输出里出现 `many too files` 之类 | 参考图给多了。多数模型最多 3–6 张参考图 |
| 生成很慢 | 一张图 20–90 秒是正常的，`2K`/`4K` 更慢。脚本单张超时是 5 分钟 |
| 提示词被拒（内容审核） | 换一种说法，别写真人、暴力、侵犯肖像权的内容 |

### 怎么换 token

1. 浏览器登录 sider.ai，按 `F12` 打开控制台，切到 Console；
2. 粘贴执行：

```js
decodeURIComponent(document.cookie.match(/token=([^;]+)/)[1]).replace(/^Bearer\s*/, "")
```

3. 复制输出的那一长串，粘贴进 `.credentials.json` 的 `token` 字段，保存。

顺手看一眼那个串里的 `exp` 字段——它是过期时间戳，除以 1000 就是秒级时间。

## 10. 它到底是怎么工作的（不看也行）

Sider 没有公开的开发者 API，这套东西是直接复用**网页版自己调用的接口**：

1. **上传**：`POST /api/create/v1/files/upload`（multipart，字段名 `file`）→ 拿到 `fileId`
2. **生成**：`POST /api/create/v1/llm/completion`，body 里 `multi_content` 放参考图和提示词，
   `creator_param` 里放模型、尺寸、比例（注意它是个 JSON **字符串**）
3. **响应是 SSE 流**，出图地址在 `tool_result` 事件的 `imageArtifacts[].url`
4. **下载**：`file-cdn.sider.ai` 的链接直接下会 403，要先请求 `/api/v1/image/sign-cookie`
   拿 CloudFront 签名 cookie，并且把域名换成签名里那个 CloudFront 域名

鉴权就一个 `Authorization: Bearer <token>`。踩过的三个坑都写在上面第 9 节了。

> 因为这是非公开接口，Sider 改版后可能失效。原始逆向记录和验证脚本在
> `D:\Code\DianaAndEleen\sider\` 目录（README.md 里有完整协议说明）。
